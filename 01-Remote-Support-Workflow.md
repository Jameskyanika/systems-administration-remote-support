# Secure Remote Support Workflow

## Overview

This document describes the workflow I use when providing remote technical support through TeamViewer, AnyDesk, Microsoft Remote Desktop and Microsoft Quick Assist.

## Tools Used

- TeamViewer
- AnyDesk
- Microsoft Remote Desktop
- Microsoft Quick Assist

## Support Workflow

```text
Receive the support request
        ↓
Confirm the affected user and device
        ↓
Understand the reported symptoms
        ↓
Select the appropriate remote-support tool
        ↓
Obtain user authorization
        ↓
Connect securely to the device
        ↓
Investigate the issue
        ↓
Apply the approved solution
        ↓
Test the affected service
        ↓
Confirm resolution with the user
        ↓
Disconnect the session
        ↓
Document the work completed
