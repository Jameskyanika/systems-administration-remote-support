# Windows Server and User Administration

The work was performed in business environments supporting daily operations. All organization names, usernames, server names and production details are generalized for confidentiality.

## User Account Administration

User accounts should be managed according to approved business requirements.

Typical activities include:

| Activity | Purpose |
|---|---|
| Create user account | Provide approved access to organizational systems |
| Reset password | Restore access after verification |
| Enable or disable account | Control whether the account can be used |
| Assign group membership | Provide role-based access |
| Review account status | Identify locked, expired or inactive accounts |
| Remove access | Protect systems when access is no longer required |
